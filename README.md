# Personal Finance Tracker

Personal Finance Tracker is a comprehensive web application that helps you manage your finances effectively. With this application, you can track your income and expenses, set budgets, manage financial goals, and gain better control over your financial health.

![Personal Finance Tracker](https://github.com/neeraj542/Personal-Finance-Tracker/assets/114648043/83946993-1e1b-41a8-ad3e-d0598bb9deb7)

## 🌟 Features

### Core Functionality
- **Transaction Management**: Track your income and expenses effortlessly with categorization
- **Multi-Currency Support**: Support for USD, EUR, and INR with real-time conversion
- **Data Export**: Export your financial data in PDF and CSV formats
- **Smart Balance Tracking**: Real-time balance calculation with positive/negative indicators

### Advanced Features  
- **Budget Management**: Set monthly budgets and track spending limits
- **Financial Goals**: Create and monitor progress towards your financial objectives
- **Expense Categories**: Organize transactions with predefined and custom categories
- **Analytics Dashboard**: Visual insights with charts and financial trends
- **Investment Tracking**: Monitor your investment portfolio and opportunities
- **Loan Management**: Access various loan options and track applications
- **Financial Reports**: Generate detailed monthly and yearly financial reports

### Technical Features
- **Data Persistence**: Automatic saving with localStorage
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **User Authentication**: Secure login and signup system
- **Dark Theme**: Modern dark interface for better user experience
- **Export Options**: Multiple export formats (PDF, CSV, Excel)

## 🚀 Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Charts**: Chart.js for data visualization
- **PDF Generation**: PDFMake for report generation
- **Icons**: Feather Icons & Font Awesome
- **Styling**: Custom CSS with modern design principles

## 📱 Responsive Design

The application is fully responsive and optimized for:
- Desktop computers (1200px+)
- Tablets (768px - 1199px)
- Mobile devices (up to 767px)

## 🛠️ Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/personal-finance-tracker.git
   ```

2. Navigate to the project directory:
   ```bash
   cd personal-finance-tracker
   ```

3. Open `index.html` in your preferred web browser or set up a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx http-server
   ```

## 📊 Usage

1. **Getting Started**: Open the application and navigate to the tracker section
2. **Add Transactions**: Input your income and expenses with descriptions and categories
3. **Set Budgets**: Define monthly spending limits for different categories
4. **Track Goals**: Create financial goals and monitor your progress
5. **View Analytics**: Access the dashboard for insights and trends
6. **Export Data**: Download your financial data in various formats
